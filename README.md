# UCL Team 1 – 4. semester – Auktionshuset

## Formål

Projektet er udarbejdet som en prototype på et auktionssystem. Formålet er at undersøge, hvordan online budgivning kan understøtte en auktion, og hvordan digitale værktøjer kan hjælpe medarbejderne med arbejdet før, under og efter auktionen.

---

## Features

- Oprettelse af kundekonto og login
- Tilmelding til auktioner og online budgivning
- Visning af auktionsresultater, køb og fakturaer
- Administration af genstande, lager og auktioner
- Registrering af betaling og afhentning

---

## Teknologier

- **C# og .NET** – programmeringssprog og platform
- **ASP.NET Core og Blazor** – webudvikling
- **PostgreSQL og Entity Framework Core** – database og dataadgang
- **SignalR og RabbitMQ** – realtidskommunikation og beskedhåndtering
- **Docker** – containerisering

---

## Projektstruktur og arkitektur

Projektet er inspireret af Clean Architecture. Vi har arbejdet med lagdeling og med at give brugergrænseflade, forretningslogik og dataadgang tydelige ansvarsområder.

---

## Installation

Lokal udvikling kræver Git, .NET 10 SDK og adgang til teamets udviklingsmiljø.

---

## Test

Projektet indeholder enhedstests og integrationstests. Udvalgte kunde- og medarbejderforløb er også afprøvet manuelt i browseren.

---

## Læringsmål

Projektet er lavet med følgende læringsmål for øje.

- Udvikle en webapplikation med ASP.NET Core og Blazor.
- Anvende lagdeling, Clean Architecture og SOLID-principper.
- Arbejde med databaser, realtidskommunikation og containerisering.
- Bruge automatiserede tests til at afprøve funktionalitet og forretningsregler.
